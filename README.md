# ollie-gilla-menu

VR mod menu for Gilla (Meta Quest). Purple juul-shape tower, wrist-pinned, built on MelonLoader.

Built by Olivia — https://discord.gg/ojailbreaks

## Controls

- **Left Y** — toggle menu
- **Left stick up/down** — move cursor
- **Left stick click** — fire selected row
- **Right grip (hold)** — fly forward while Fly is on
- **Right A** — teleport to checkpoint
- **Right B** — set checkpoint

## Features

- ESP (tint rigs magenta)
- Platforms (spawn under right hand)
- Fly (hold grip)
- Long arms, noclip, low/high gravity
- Nametags
- Purple Haze / Acid Lime / Blood Rail themes, RGB mode
- Save / load config

## Install (Quest standalone via sideload)

1. Install LemonLoader on your Quest (Quest fork of MelonLoader): https://github.com/LemonLoader/LemonLoader
2. Download `OllieGillaMenu.dll` from the Releases page.
3. Drop it in `/sdcard/Android/data/<gilla-package>/files/Mods/` using any file manager or `adb push`.
4. Launch Gilla, press **Y** on left Touch.
